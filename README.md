# AO3 Comment Monitor Bot

Telegram-бот для мониторинга комментариев на Archive of Our Own (AO3): отправляет уведомления о новых комментариях под всеми работами указанного пользователя AO3 в выбранный топик группового чата.

## Требования

- Python 3.9+
- Аккаунт Telegram и токен бота (от [@BotFather](https://t.me/BotFather))
- Группа в Telegram с включёнными топиками (темами)

## Установка

1. Клонируйте репозиторий или скопируйте файлы проекта.

2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv venv
   venv\Scripts\activate   # Windows
   # source venv/bin/activate  # Linux/macOS
   pip install -r requirements.txt
   ```

3. Настройте конфигурацию:

   - Скопируйте `config.ini.example` в `config.ini`.
   - Откройте `config.ini` и укажите:
     - `BOT_TOKEN` — токен бота от BotFather.
     - `USERNAME` в секции `[AO3]` — имя пользователя AO3, за которым следить (например, `fandom_ghoap`).
   - В секции `[AO3]` укажите `PASSWORD` (пароль от аккаунта AO3) или переменную окружения `AO3_PASSWORD`. Бот работает только через Inbox и отправляет уведомления только о новых комментариях (кудасы игнорируются).
   - При необходимости измените `CHECK_INTERVAL` (интервал проверки в секундах) и `REQUEST_DELAY` (задержка между запросами к AO3).

   Секреты можно задать переменными окружения: `BOT_TOKEN`, `AO3_USERNAME`, `AO3_PASSWORD` — они имеют приоритет над `config.ini`. **Без `config.ini`** бот может работать только из переменных окружения (удобно для Railway и других облачных платформ).

## Деплой на Railway

1. Создайте проект на [Railway](https://railway.app), подключите репозиторий (GitHub/GitLab) или загрузите код.

2. **Переменные окружения** (обязательно задайте в Railway → Variables):
   - `BOT_TOKEN` — токен бота от @BotFather
   - `AO3_USERNAME` — логин AO3
   - `AO3_PASSWORD` — пароль AO3  
   Опционально: `CHECK_INTERVAL` (по умолчанию 180), `REQUEST_DELAY` (по умолчанию 15), `STATE_FILE`, `LOG_FILE`.

3. **Команда запуска**: в настройках сервиса укажите **Start Command** = `python main.py` (или оставьте пустым, если Railway подхватит Procfile с `worker: python main.py`).

4. **Тип сервиса**: это фоновый воркер (не веб-сервер). В Railway выберите процесс **Worker** или сервис без HTTP-порта.

5. Состояние (`bot_state.json`) по умолчанию пишется в файловую систему контейнера — при перезапуске/редеплое оно сбрасывается. Для сохранения между деплоями подключите **Volume** к директории проекта или задайте `STATE_FILE` в путь внутри volume.

## Запуск

1. Запустите бота:

   ```bash
   python main.py
   ```

2. Добавьте бота в группу с топиками (супергруппу с включёнными темами).

3. В том топике, куда должны приходить уведомления, отправьте команду:
   - `/set_topic` или `/start`

   Бот ответит, что топик установлен. Дальше все новые комментарии AO3 будут приходить только в этот топик.

4. Бот работает в фоне: раз в `CHECK_INTERVAL` секунд он загружает раздел Inbox AO3 (через сессию), отбирает только комментарии и отправляет уведомления о новых (состояние хранится в `bot_state.json`).

## Файлы состояния и логов

- `bot_state.json` — список уже обработанных комментариев (по хешам) и выбранный топик. Создаётся автоматически. Удаление файла приведёт к повторной отправке всех комментариев при следующей проверке.
- `bot.log` — лог работы (если в `config.ini` указан `LOG_FILE = bot.log`).

## Безопасность аккаунта AO3

Чтобы снизить риск ограничений со стороны AO3 при автоматическом доступе:

- **Один вход на сессию** — бот входит в AO3 один раз при старте и дальше только читает Inbox; повторных логинов нет.
- **Редкие запросы** — один запрос за цикл (страница Inbox). Увеличьте `CHECK_INTERVAL` (например 300–600 секунд) и `REQUEST_DELAY` (15–30 секунд), не уменьшайте их до минимума.
- **Не держать несколько ботов на одном аккаунте** — один инстанс бота на один AO3-аккаунт.
- **Секреты только в окружении** — на Railway и в проде не кладите пароль в `config.ini` в репозитории; используйте переменные окружения. Файл `config.ini` в проекте в `.gitignore`.
- При появлении 429 (rate limit) или ошибок входа — увеличьте паузы и не перезапускайте бота слишком часто.

Гарантий нет: AO3 может менять правила; использование бота — на ваш риск.

## Критерии приёмки

- Уведомления приходят в течение одного цикла проверки после появления нового комментария.
- Каждый комментарий порождает ровно одно сообщение в Telegram (без дублей).
- Все уведомления приходят в топик, выбранный командой `/set_topic`.
- При временной недоступности AO3 или Telegram бот логирует ошибку, делает паузу и продолжает работу в следующем цикле.
